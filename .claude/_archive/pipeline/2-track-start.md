# Step 2 — Track Start (before coding)

## Update tracking docs BEFORE any code is written

### BACKLOG.md

- [ ] Update task status: planned → in-progress
- [ ] Note which agents will work on what

### Issues (E2E-TESTS.md or app-specific)

- [ ] Create ISSUE-xxx entries for known bugs
- [ ] Mark existing tests as ⏳ (needs retest) if the code will touch them
- [ ] Add new test cases for new features (status: ⏳)

### Principle

Update tracking FIRST so that if the session is interrupted,
the next Claude instance knows exactly what's in progress.
