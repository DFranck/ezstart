# 📦 api-boilerplate

Backend API service for boilerplate

## 🚀 Getting Started

```bash
# 1️⃣ Clone only this package
git clone <your-repo-url>
cd api

# 2️⃣ Install dependencies
pnpm install

# 3️⃣ Run the package
pnpm dev
```
