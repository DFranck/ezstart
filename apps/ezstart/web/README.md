# 📦 web-ezstart

Frontend web application for ezstart

## 🚀 Getting Started

```bash
# 1️⃣ Clone only this package
git clone <your-repo-url>
cd web

# 2️⃣ Install dependencies
pnpm install

# 3️⃣ Run the package
pnpm dev
```
