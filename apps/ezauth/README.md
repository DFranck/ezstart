# EZAuth

Centralized SSO authentication service for all @ezstart apps.

## Run

`pnpm dev:bill` or `pnpm dev:gp` or `pnpm dev:fs` or `pnpm dev:ga` (starts with dependent apps)

## Env vars

Copy `.env.example` to `.env.local` in both `api/` and `web/`.

## Ports

- API: 6110
- Web: 6111
