## 💡 Best Practices Reference

### One-Page Landing Structure
```
1. Hero Section
   - Headline (H1): Clear value proposition
   - Subheadline: Supporting detail
   - CTA: Primary action button
   - Hero image/video

2. Social Proof
   - Logos of clients/partners
   - Testimonials
   - Stats (users, success metrics)

3. Features/Benefits
   - 3-4 key benefits with icons
   - How it works (3-step process)

4. Demo/Product Showcase
   - Screenshots
   - Video walkthrough

5. Pricing (if applicable)
   - Clear tiers
   - Most popular highlighted

6. Final CTA
   - Repeat primary action
   - Remove objections

7. Footer
   - Links
   - Contact
   - Legal
```

### Image Optimization Checklist
- [ ] Use WebP format (with PNG/JPG fallback)
- [ ] Implement lazy loading (loading="lazy")
- [ ] Responsive images (srcset)
- [ ] Proper dimensions (width/height to prevent CLS)
- [ ] Compress images (TinyPNG, Squoosh)
- [ ] CDN delivery (Vercel Image Optimization)

### Font Loading Strategy
```tsx
// Next.js 14+ with next/font
import { Inter } from 'next/font/google'

const inter = Inter({
  subsets: ['latin'],
  display: 'swap', // Prevents FOIT (Flash of Invisible Text)
  preload: true,
})
```
