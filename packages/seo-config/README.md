# @ezstart/seo-config

Centralized SEO with robots.txt, sitemap.xml, and metadata helpers for all web apps.

## Install

`pnpm add @ezstart/seo-config`

## Usage

```typescript
import { createMetadata } from '@ezstart/seo-config/metadata'
import { createRobots } from '@ezstart/seo-config/robots'
import { createSitemap } from '@ezstart/seo-config/sitemap'
```

## Used by

All web apps.
