# @ezstart/next-config

Shared Next.js configuration with PWA and i18n support for all web apps.

## Install

`pnpm add -D @ezstart/next-config`

## Usage

```javascript
// next.config.mjs
import { withI18n } from '@ezstart/next-config/withI18n'
export default withI18n({ /* next config */ })
```

## Used by

All web apps.
