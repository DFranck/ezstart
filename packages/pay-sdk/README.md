# @ezstart/pay-sdk

React SDK for EZPay universal payment system (donations, purchases, subscriptions).

## Install

`pnpm add @ezstart/pay-sdk`

## Usage

```typescript
import { PayProvider, DonateModal, usePay } from '@ezstart/pay-sdk'
// Server-side
import { verifyPayment } from '@ezstart/pay-sdk/server'
```

## Used by

- apps/ezpay (web, api)
- apps/fengshui (web)
