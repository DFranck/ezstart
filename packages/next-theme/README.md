# @ezstart/next-theme

Hydration-safe dark/light theme provider for Next.js apps.

## Install

`pnpm add @ezstart/next-theme`

## Usage

```typescript
import { ThemeProvider, useTheme } from '@ezstart/next-theme'
import { ThemeToggle } from '@ezstart/next-theme/components'
```

## Used by

All web apps.
