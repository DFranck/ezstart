# @ezstart/ocr-sdk

OCR SDK with Tesseract.js engine and extensible game-specific parsers.

## Install

`pnpm add @ezstart/ocr-sdk`

## Usage

```typescript
import { createOCREngine } from '@ezstart/ocr-sdk'
import type { OCRResult } from '@ezstart/ocr-sdk/types'
```
