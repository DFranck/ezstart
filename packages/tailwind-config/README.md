# @ezstart/tailwind-config

Shared Tailwind CSS configuration with custom theme, colors, and plugins for all web apps.

## Install

`pnpm add -D @ezstart/tailwind-config`

## Usage

```javascript
// tailwind.config.ts
import baseConfig from '@ezstart/tailwind-config/base'
export default { ...baseConfig, content: ['./src/**/*.tsx'] }
```

## Used by

All web apps.
