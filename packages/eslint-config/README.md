# @ezstart/eslint-config

Centralized ESLint configuration for all apps and packages.

## Install

`pnpm add -D @ezstart/eslint-config`

## Usage

```javascript
// eslint.config.mjs
import config from '@ezstart/eslint-config'
export default config
```

## Used by

All web apps, select APIs, and packages (express-core, ui).
