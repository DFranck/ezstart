# @ezstart/ai-sdk

Unified AI SDK with multi-provider support (OpenAI, Gemini, Claude) for backend and frontend.

## Install

`pnpm add @ezstart/ai-sdk`

## Usage

```typescript
// Backend
import { createAIService } from '@ezstart/ai-sdk'

// Frontend
import { AIChat } from '@ezstart/ai-sdk/client'
```

## Used by

- apps/ezbill (api)
- apps/green-pulse (api, web)
