# @ezstart/ui

Accessible, reusable UI component library built on shadcn/Radix for all web apps.

## Install

`pnpm add @ezstart/ui`

## Usage

```typescript
import { Button, Dialog, Input } from '@ezstart/ui/components'
import { useMediaQuery } from '@ezstart/ui/hooks'
import { cn } from '@ezstart/ui/lib'
```

## Adding components

```bash
pnpm --filter @ezstart/ui ui:add [component-name]
```

## Used by

All web apps and packages/auth-sdk, pay-sdk, rbac, next-theme.
