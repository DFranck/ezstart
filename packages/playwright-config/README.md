# @ezstart/playwright-config

Shared Playwright E2E testing configuration for all web apps.

## Install

`pnpm add -D @ezstart/playwright-config`

## Usage

```typescript
// playwright.config.ts
import { createConfig } from '@ezstart/playwright-config'
export default createConfig({ port: 6121 })
```

## Used by

No apps currently use this (available for E2E testing setup).
